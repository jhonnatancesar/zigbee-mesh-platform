# Glossario

| Termo | Definicao neste projeto |
| --- | --- |
| ADR | Registro de uma decisao arquitetural ja aprovada. |
| API administrativa | Interface destinada a administracao da plataforma. |
| Banco proprio | Persistencia sob controle da plataforma e fonte da verdade. |
| Coordenador | Componente que forma e coordena a malha Zigbee. |
| End device | Dispositivo final da malha Zigbee; inclui o sensor proprietario do MVP. |
| HAL | Camada de abstracao de hardware, desacoplada da logica de dominio. |
| Home Assistant | Cliente da plataforma no MVP. |
| MVP | Escopo inicial definido no Playbook. |
| OTA | Atualizacao remota de software, assinada e com rollback no MVP. |
| RFC | Proposta tecnica pendente de analise e validacao. |
| Router | Componente Zigbee que encaminha trafego na malha. |
| TASK | Unidade unica de trabalho, executada e validada antes da proxima. |
