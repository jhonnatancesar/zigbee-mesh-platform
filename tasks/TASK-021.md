# TASK-021 — Planejamento de LoRa (V2)

## Objetivo

Definir a extensão LoRa prevista para V2 sem alterar o MVP.

## Contexto

LoRa é explicitamente excluída do MVP e prevista no roadmap V2.

## Dependências

TASK-020 validada e autorização específica para V2.

## Escopo

Elaborar RFC de requisitos, interoperabilidade, segurança e impacto arquitetural.

## Arquivos permitidos

`docs/`, `rfc/`, `adr/`, `tasks/TASK-021.md`, `CHANGELOG.md`.

## Arquivos proibidos

Implementação LoRa, alterações funcionais do MVP, hardware de produção.

## Critérios de aceite

- Impactos em eventos, dados e segurança estão documentados.
- Nenhuma alteração do MVP é realizada sem aprovação.

## Testes obrigatórios

Revisão arquitetural e de segurança.

## Resultado esperado

RFC V2 pronta para validação.
